# Node-Express-EJS-CRUD

Simple Blog App built using **Node.js, Express.js, MongoDB, Mongoose, and EJS** to demonstrate basic **CRUD (Create, Read, Update, Delete)** operations.

## Features
- Create blog posts
- View all posts
- View a single post
- Edit posts
- Delete posts

## Tech Stack
- Node.js
- Express.js
- MongoDB
- Mongoose
- EJS

## Installation

Clone the repository:

```bash
git clone https://github.com/yourusername/Node-Express-EJS-CRUD.git
cd Node-Express-EJS-CRUD
```

Install dependencies:

```bash
npm install
```

## Run the App

Make sure **MongoDB is running**, then start the server:

```bash
npm start
```

Open your browser:

```
http://localhost:3000
```
